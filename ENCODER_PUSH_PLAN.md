### 4. Make a predicted continuous plan causally affect the encoder policy — conditional must have

**Hypothesis/evidence:** our current encoder reasoning arms do not implement the causal winner’s mechanism. `QWen3_EncDec.forward()` explicitly returns encoder states to the PI action expert and states that it “never sees the reasoning.” U/V decoder-CoT arms therefore add an auxiliary decoder loss only; their full-protocol scores are75.975% and75.875%. The MLM slots expose parallel masked states but semantic MLM underperforms its slot-only control (73.925% versus75.525%). `zsupdec` lets the causal decoder read shared z, but the action head still receives encoder z rather than decoder reasoning states and scores76.250%. This leaves a clean missing test: use the bidirectional encoder for perception, the causal decoder for an explicit plan, and make the action head consume that plan.

The pretraining auxiliary sweep does not close this gap. Dense predicts a point/box heatmap from every encoder patch; trace-linear predicts six ordered waypoints from a temporary encoder CLS token; trace-time predicts occupancy, order and sub-patch offsets; B2 readout tokens predict point/box sets; the reverse arm uses114 encoder queries to predict FAST action tokens while the decoder predicts a six-point trace. These targets shape the encoder during pretraining, but their heads or temporary queries are absent from the downstream rollout interface. The action model consumes neither their decoded plan nor their prediction errors. The only dense-backbone policy rollout averages72.138% versus73.125% for v5 PI, but the backbones have different pretraining histories, so this is negative evidence rather than an isolated dense-loss effect. The clean full-epoch dense continuation reduces the spatial/VQA aggregate0.690442→0.671040 but has no policy rollout. Therefore do not treat “reasoning/readout auxiliary loss” as equivalent to “reasoning-conditioned action generation.”

The current graph is `h=Encoder(x); prediction=AuxHead(h); action=GR00T(h or z)`. Auxiliary loss changes `h` through backpropagation, but `prediction` is discarded. An action readout from the same hidden state is not equivalent to conditioning on the prediction: GR00T may ignore the plan-decodable subspace, and there is no wrong-plan intervention. Shared-z is the closest existing mechanism: the supervised128D z is consumed by GR00T through AdaLN and encoder memory is completely masked in the winning runs. Because the current auxiliary predictions are deterministic functions of z or h, simply concatenating a prediction derived from the same z adds no information; it only changes optimization. A useful new path must expose an ordered low-dimensional bottleneck from richer encoder memory and/or cause a second round of visual-language computation.

**Stage A — primary mechanism experiment, tied two-pass bidirectional trace re-encoding without shared z:** the earlier direct-token proposal is not the mechanism used by the causal CoT winner. In that model rollout first generates a trace, then re-encodes prompt plus generated trace, and GR00T consumes the resulting contextual hidden states. Mirror that information flow without requiring language generation. Pass1 runs the bidirectional encoder over images, instruction/state and five typed masked trace slots, matching the winning causal prompt. A strict linear head maps the five slot states to ordered normalized `(x,y)` waypoints plus confidence/phase. Round or jitter the coordinates, Fourier/MLP-embed the decoded values as typed trace inputs, and run the same weight-tied encoder a second time over images, instruction/state and those predicted trace inputs. Because pass2 is bidirectional, the trace can refine visual, language and state representations and is itself re-grounded against them. For the first run, omit shared z and let GR00T cross-attend to all pass2 states. This is the closest match to the causal winner and isolates whether bidirectional trace re-encoding helps before combining it with the already successful z pathway.

The deployable action loss always uses pass1 predictions in pass2. Initially stop-gradient across the rounded coordinate boundary so the only information in the loop is the declared trace; train pass1 with its trace loss. Ground-truth traces are an oracle diagnostic, not the training input to the deployed branch. The first comparison is `no_z_all_pass2`: one-pass/no-z full encoder memory versus two-pass/no-z predicted trace versus two-pass/no-z zero/dummy trace. Wrong-scene and temporally shuffled traces preserve the second pass while testing whether aligned plan content matters. Otherwise a gain could come only from doubling encoder computation. Do not make `no_z_trace_only` the first run: it simultaneously removes z and compresses all action context to five states, and the existing small causal trace-only roots are weak.

**Stage A2 — performance combination after the mechanism smoke:** form shared z from pass2 and give GR00T pass2 z through AdaLN plus the five contextual trace states through cross-attention, masking ordinary memory. ### 9. Camera-routed shared-z queries — conditional second architecture candidate; would strengthen the paper

**Hypothesis/evidence:** DROID ext+wrist dilution motivates testing competition between camera token groups, but those probes are not from the best shared-z policy. Use verified image-token boundaries and camera IDs; never split the sequence in half.
